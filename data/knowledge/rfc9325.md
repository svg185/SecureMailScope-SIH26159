# RFC 9325 — Recommendations for Secure Use of Transport Layer Security

## Modern TLS versions
Use TLS 1.2 or TLS 1.3 for contemporary secure communication. Older versions require special justification and are treated by SecureMailScope as deprecated findings.

## Cipher suites
Prefer modern authenticated-encryption cipher suites such as AES-GCM or ChaCha20-Poly1305. Avoid legacy algorithms such as RC4 and 3DES.

## Key exchange
Ephemeral key exchange such as ECDHE provides forward secrecy when correctly deployed.
